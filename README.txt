Animal Rescue and Reporting System - Simple Website Prototype

How to run:
1. Extract the ZIP file.
2. Open index.html in Chrome or any browser.
3. Use Report Animal form to create a report.
4. Go to Admin Dashboard to update status or assign volunteer.
5. Go to Track Status to view report progress.

Main prototype sections:
- Home page
- Report injured animal form
- Track rescue status
- Volunteer registration
- NGO admin dashboard

Technologies used:
- HTML
- CSS
- JavaScript
- Browser localStorage for demo data

Note:
This is a frontend prototype. It does not need a server or database. For a final project, PHP/MySQL or Node.js/MySQL can be added as backend.
